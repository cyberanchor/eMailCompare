How it works

  • One Hugo project in site/ with the PaperMod theme. A variant is a folder in site/config/ plus a stylesheet in site/assets/emc/variants/; site/build.sh builds them all into site/public/.
  • Favicons are stored in site/assets/favicons/ and re-encoded by Hugo, so the pages never request anything from the providers or third parties.
  • Screenshots: put site/assets/screenshots/<domain-with-dashes>.png (e.g. protonmail-ch.png) and rebuild; the frame on the provider page shows it.
  • Each preview has a design switcher in the bottom-left corner. The current site: interactive table · static table.
