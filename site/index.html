How it works

  • Shared code lives in site/_shared/: it reads emails.csv and the README, applies the same colour rules as the current site and creates one page per provider. Each theme folder only adds its layout and colours.
  • Text pages are Markdown (_shared/content/about.md); the table can be placed in any Markdown page with the emc-table, emc-stats and emc-legend shortcodes.
  • Rebuild with site/build.sh (needs Hugo extended and git); site/build.sh --serve hextra starts a live preview.
  • The current site: interactive table · static table.
